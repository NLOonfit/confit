# Мафия 2 · Конвертер моделей

Настольное приложение для Windows 10/11 x64, версия 0.2.1. Открывает модели из SDS оригинальной Mafia II (2010), показывает их во вьюпорте и экспортирует в `.blend`, FBX с текстурами или GLB.

## Скачать приложение с GitHub

1. Откройте [сборки ветки codex/mafia2-converter](https://github.com/NLOonfit/confit/actions?query=branch%3Acodex%2Fmafia2-converter).
2. Выберите успешный запуск **Build Mafia II converter for Windows**.
3. В разделе **Artifacts** скачайте **Mafia2Converter-Windows-x64**. Для скачивания артефактов GitHub обычно требуется вход в аккаунт.
4. Распакуйте ZIP целиком в отдельную папку. Запустите `Mafia2Converter.exe`, сохранив рядом остальные файлы.

ZIP появляется только после успешной сборки Actions. Исходники сами по себе не являются готовым EXE. Если Actions отключён для репозитория, включите его в настройках GitHub; пока workflow находится только в отдельной ветке, сборка запускается её обновлением. Артефакты хранятся 30 дней. После переноса workflow в основную ветку также доступен ручной запуск Run workflow.

## Работа с моделями

1. Для экспорта в FBX / Blend установите Blender 4.x. Нажмите **Выбрать Blender** и укажите `blender.exe`. Python отдельно устанавливать не нужно.
2. Выберите один `.sds`. Программа распакует архив, найдёт геометрию, UV, нормали и DDS. Также доступны OBJ + MTL, GLB, glTF с локальными связанными файлами.
3. Выберите LOD. Для `albert.sds` по умолчанию подходит ось вверх X; ось можно изменить для других ресурсов.
4. Цветовая текстура выбирается по суффиксу `d.dds`, карта нормалей — по `n.dds`. Для каждого материала можно изменить привязки. LOD1 использует `dlod.dds`, если он присутствует. Это соглашение имён, а не восстановление игрового шейдера по хешу.
5. Нажмите **Экспортировать модель**. Blend содержит упакованные изображения. ZIP с FBX содержит `model.fbx` и папку `textures` с PNG; изображения также встроены в FBX. GLB можно импортировать в Blender через glTF 2.0.

Поддержка SDS проверена на `albert.sds`: 15 ресурсов, 7 уникальных DDS, LOD0 — 3726 вершин / 5395 треугольников; LOD1 — 383 вершины / 480 треугольников. Сжатие этого файла — zlib.

## Ограничения

- Поддерживаются PC SDS v19 и FrameResource v28 с одной геометрией и одним набором материалов.
- Экспорт статический: скелет, анимации, игровые шейдеры, specular и facial-expression материалы не восстанавливаются.
- Сцены SDS, несколько геометрий, консольные варианты, шифрование и Oodle пока не поддерживаются.
- У стандартных моделей UV и текстуры сохраняются; DDS зависит от поддерживаемой компрессии и возможностей GPU. Для OBJ поддерживается один MTL.
- EXE не подписан сертификатом. Запуск на Windows не проверен в облачной Linux-среде; интерфейс и настоящий экспорт проверяются Chromium и Blender отдельно.

## Разработка и сборка

Нужны Node.js 24 и Blender 4.x:

```sh
cd mafia2-converter
npm ci
npm run build
npm start
```

Собрать папку приложения для Windows:

```sh
npm run package:win
```

Результат: `release/Mafia2Converter-win32-x64`. Для сборки нужны официальные Electron-артефакты с GitHub; проверка контрольных сумм и TLS остаётся включённой.

В ограниченной облачной среде для проверки интерфейса можно установить зависимости с `ELECTRON_SKIP_BINARY_DOWNLOAD=1 npm ci`: это пропускает загрузку Linux Electron, но не проверяет запуск настольного окна. Windows-артефакт упаковщик скачивает отдельно.

## Проверка на реальном SDS

После `npm run build` в Linux с установленными Chromium и Blender:

```sh
npm run test:sds -- /path/to/albert.sds
```

Пути при необходимости задаются через `CHROMIUM_PATH` и `BLENDER_PATH`. Тест проверяет импорт, LOD, FBX / Blend, повторное открытие в Blender, UV, текстуры, ориентацию и обработку повреждённого SDS. Образец игры не включён в репозиторий и не отправляется в GitHub Actions.

Исходный `confit.xml` этого репозитория не относится к приложению и остаётся без изменений.
