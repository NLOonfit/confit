# Поддержка формата

`src/sds.js` — независимо написанный JavaScript-читатель бинарных ресурсов; содержимое SDS рассматривается как данные и не выполняется. Изучение формата опирается на предоставленный образец и публичные сведения об SDS, включая Gibbed.Illusion / Gibbed.Mafia2 Rick (gibbed). Код MafiaToolkit под PolyForm Strict не включён в проект.

Обработаны PC SDS v19, ресурсные заголовки по 30 байт, UEzl zlib-блоки с 32-байтным заголовком, пулы вершин / индексов v2 и FrameResource v28 с одной геометрией. Квантованные позиции используют масштаб и смещение из геометрии; нормали — байтовые компоненты; UV0 — half float. Декларации вершин задают смещения компонентов. Индексы читаются как uint16 / uint32. Группы материала должны покрывать весь индексный буфер без перекрытия.

DDS именуются по XML-метаданным самого SDS. Если для хеша есть Texture и отдельный Mipmap, выбирается изображение большего разрешения. Привязки цветового атласа и карты нормалей определяются соглашениями имён и доступны для ручного изменения. Игровая библиотека материалов по хешам не восстанавливается.

Скелетные блоки не интерпретируются; меш экспортируется статически. Корневые игровые трансформации не читаются. Пользователь явно выбирает локальную ось вверх: для albert подходит X. Этот поворот сохраняется при экспорте.

Проверяются границы чтения, размер распаковки, результат zlib, длины буферов, конечность координат, диапазон индексов и покрытие материала. Специальные контрольные поля контейнера не проверяются: это не инструмент проверки подлинности игровых файлов. Неподдерживаемые варианты возвращают сообщение, сохраняя предыдущую загруженную модель.
