Просмотр и экспорт моделей · v0.2.1

01 / Импорт

Выберите один SDS из Mafia II (2010). Для OBJ или glTF выбирайте модель и связанные файлы вместе.

SDS: PC v19 / FrameResource v28 с одной геометрией. Проверено на albert.sds. Сцены и зашифрованные контейнеры пока не поддерживаются.

Ресурсы SDS

Для персонажей по умолчанию X, для остальных моделей — Z. Цвет и нормали выбираются по именам DDS. Привязки можно изменить; игровые шейдеры не восстанавливаются.

02 / Вьюпорт

Левая кнопка — вращение, правая — перемещение, колесо — масштаб.

03 / Blender

Для FBX и Blend установите Blender 4.x и укажите blender.exe. Экспортируется выбранный LOD с материалами и изображениями. Риг и анимации пока не поддерживаются.
