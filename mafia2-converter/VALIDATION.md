# Проверка восстановленной версии 0.2.1

Команды выполнены в облачной Linux-среде с Node.js 24, Chromium и Blender 4.3.2:

```sh
npm run build
npm run test:sds -- /path/to/albert.sds
```

Результат: проверка завершилась успешно.

- SDS распакован: 15 ресурсов, 7 DDS. LOD0 — 5395 треугольников, LOD1 — 480.
- Экспортируются GLB, Blend и ZIP с FBX.
- Цветовой атлас и карта нормалей связаны с материалами и не дублируются для каждого материала в GLB.
- GLB повторно открыт во вьюпорте; сохранены 5395 треугольников.
- Blend и FBX повторно открыты реальным Blender: сохранены геометрия, UV, читаемые изображения и вертикальная ориентация. Изображения в Blend упакованы.
- Экспорт LOD1 повторно открыт в Blender: 480 треугольников.
- Неподдерживаемый и обрезанный SDS отклоняются; предыдущая модель остаётся доступна.
- Демонстрационная модель, каркас и фокусировка работают без ошибок JavaScript.

Образец не включён в репозиторий. Проверка не доказывает поддержку остальных вариантов SDS, ригов, анимаций или игровых шейдеров. Выполнение Windows EXE здесь не проверено; workflow выполняет сборку Windows и проверку комплектности файлов.
